# エコー3D再構成ビューア

扇状にスイープした超音波 B モード画像・動画から組んだ 3D ボリュームを、ブラウザで見るためのページです（COMOMO、未踏IT 2026）。

公開ページ: https://comomoteam.github.io/echo3d-viewer/

- サンプル1〜3の再構成結果
- 画像が撮影角度どおりに1枚ずつ置かれていく再構築アニメーション
- 陰影（勾配による Phong 照明）つきのボリュームレンダと直交3断面
- サンプル1〜4（どれも前腕屈側）と、前腕屈側・遠位の動画 4 本（2026-11-03）の構造の色分け。筋・動脈・神経・骨などを構造ごとに色を付けて表示・切り替えできる。名前は参照の超音波像との見比べと文献の正常値での確認による当てはめで、確定したものではない
- V3 リグでプローブを傾けずに平行移動させた掃引 15 本（2026-11-16、右腕内側・上腕・ふくらはぎ）。断面をモーターの位置どおりに並べて組んだもの。公開版はボクセルを 2 おきに間引いて 0.2 mm にしている
- 斑点の平滑化(裏で計算し、0.1 mm のボリュームでも数秒)、明暗の反転、3方向の切り取り

このリポジトリは閲覧専用の静的版だけを置いています。再構成を実行するローカル版のソースは非公開です。
